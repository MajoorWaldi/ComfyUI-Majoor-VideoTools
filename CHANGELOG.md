# Changelog

## Current development version

- Generate Shot (API) takes its references as ordinary inputs and hands them to the API node through two internal nodes (Held Image, Held Audio): a reference that is not there (a lazy switch with nothing to give) is simply left out, so the `use_image_6` switch is gone. The cost estimate can read the price badges from another ComfyUI (`badges=` of `estimate`), which HyperKut Studio uses.
- Cost guard for API video models: `max_api_seconds` (120 by default) and `max_api_usd` (0 = no limit) on Generator Select cap what one run asks from an API model, retries included. The dollars are the price badges of the partner nodes added up: the badge (a JSONata expression) of the node that Generate Shot creates is evaluated on the settings of each take (`jsonata-python`, new in requirements.txt; without it the estimate keeps the seconds). Deploy Shots writes the estimate of the whole edit in its report (a range when a reference video is wired, since the badge then gives one) and asks before a deployment that would go over; Generate Shot (API) logs the price of each take and stops before the take that would pass a budget, without calling the model. A generator file may carry `price_per_second` and `price_unit` as a fallback. `scripts/add_cost_guard.py` adds the controls to a recipe.
- Prompt writers per video model: new `shot_writer` skills `seedance_shot_prompt` (@Image/@Video/@Audio tags, timed action, quoted lines), `wan_shot_prompt` (the same tags in Wan's subject-scene-motion-camera order) and `ltx_shot_prompt` (one present-tense paragraph from the first picture). The `prompt_skill` of each file in `generators/` names its writer; Edit Skills takes an optional `generator` and swaps an H3/shot writer for it, and the Shot sub-graph of the Creative workflows passes the VIDEO MODEL to it (`scripts/route_prompt_skill.py`). The message to the LLM names the model (`Seedance 2.5 INPUT MODE: reference`).
- Generate Shot (API): one node that makes the take of a shot with Seedance 2.5, Wan 3.0 or LTX 2.5 from the same settings (prompt, seconds, aspect ratio, resolution, reference pictures, frames of a reference video, audio). It creates the node the model needs when the graph runs, so only the chosen model is called. The SECATOR Creative Text and Music workflows have a VIDEO MODEL control (Generator Select): H3 stays the local default, an API model switches the takes of every shot block (lazy switches), Create Timeline plans for it (new optional `generator` input) and Deploy Shots gives each shot its own seed. `scripts/add_generator_router.py` adds the router to a recipe. Remix keeps H3 only.
- Generator registry: one file per video model in `generators/` (MiniMax H3, Seedance 2.5, Wan 3.0, LTX 2.5 Fast and Pro) says how long a take must be (frame grid or whole seconds), how many pictures, videos and audios it takes and whether it makes sound. `generation_profile` of Create Timeline now lists those models, plans are checked against them (a shot longer than the model can make is reported), Select Shot asks a model that works in seconds for exactly those seconds, and the new Generator Select, Generator Is and Generator Limits nodes (and `/majoor/generators`) let a shot block switch between models so that only the chosen one runs.
- Apply Shot Metadata writes the graph that made a take into the file (`prompt` and `workflow` tags, like Save Video), so dropping the take in ComfyUI reopens it. `embed_workflow` (default on) or `MAJOOR_EMBED_WORKFLOW=0` turns it off; a stored take handed back is left as it is.
- Music and Hit sync cuts are no longer joined into bursts: every cut is its own shot at its own length. H3 generates at least 22 frames for it (Text and Music workflows), and Apply Shot Metadata with `align_to_music` shows the part of that longer take whose motion lands on the music, anywhere in the take for a cut shorter than 22 frames.
- Hit sync, a new editing rhythm of Create Timeline (`music_edit_mode` = `hits`): a cut on the kicks, the snares, the entries of the bass (new `bass_hits`, which follows the level of the low band, so a smooth bass or a sub drop is heard) and the start of each word or burst of voice, the cut pace deciding how many are kept. Dense hits become a burst inside one take. Remix retime: a short reference is held to 5 frames, which MiniMax H3 requires.
- Remix Plan node and remix_planner skill: the story line, the person, the place and the source of each shot laid on the detected shots of a remix, cuts unchanged. Planned Shot Source renders a shot kept as the source has it (render_source kind "original"); Shot Memory takes the number of reference pictures that come before it.
- Shot identification, scene splitting, metadata and retained-take assembly.
- Shared Timeline Edit editor and Studio adapter for frame-based manual montage.
- Visual workflows and exported Studio API graphs for Remix, Text and Music.
- Gemma planning, MiniMax H3 video and YuE2 music in the maintained Studio workflow.
- Shot-local prompts, narrative handoff, optional location/pose/mask branches and audio-event timing.
- Experimental unified HyperFrames graphics and Tone-generated optional sound palette.
- Explicit installers, portable preset inputs and documented model/dependency/media terms.

The legacy SECATOR workflow filenames remain compatible. HyperKut Studio is distributed separately and remains beta. Finishing is experimental and starts disabled in the Studio.

See [roadmap](ROADMAP.md), [model inventory](docs/models-and-downloads.md) and [licenses](LICENSES.md).


## Unreleased — H3 performance pipeline

- **Lip Sync Check** (`MajoorLipSyncCheck`, `core/lipsync.py`): compares the opening of the mouth region (a part of the face above it is taken away, so a head that bobs does not count) with the loudness of the voice, frame by frame, with a delay up to 0.25 s; the score must also beat what an unrelated mouth reaches by chance (`chance` in the report). Verdicts `pass`, `fail` and `unmeasured` (no face, no voice, too short, or no face detector in this OpenCV: give `mouth_region`). Outputs `ok`, `retake` and `next_seed` for a switch that makes the shot again. It measures opening, not phonemes.
- **Transcribe Voice** (`MajoorTranscribeVoice`, `core/transcribe.py`): reads the words of a track with Whisper (faster-whisper, a model folder in `models/faster-whisper`, no download) and gives `words_json` for Music Words and Create Timeline and `lyrics_text` for the planners' prompt. A track with no voice gives nothing. The Studio music workflow uses it.
- **Varied pacing on the music grid**: `Create Timeline` with `source=music` and `music_edit_mode` adaptive, random or phrases cuts with the same seeded pacing as the final edit (long holds, short cuts, bursts of very short shots) instead of one cut per grid step, so the planner is no longer handed a take for every beat. The Studio gives it the editing mode of the job.
- **Bursts are one generation**: with the varied pacing, runs of cuts too short for H3 (under 22 frames) are joined into one take whose cuts become its sub-cuts, so thirteen cuts on a track cost seven generations.
- **Shot Memory** (`MajoorSaveShotMemory`, `MajoorShotMemory`, `core/memory.py`): the sharpest frame of each kept take is filed by character in the project's `cache/memory`; the next shots of that character get it as one more H3 picture, with a sentence that names it, so a character invented from text keeps its face from shot to shot. Not used when you give reference pictures. The Studio's music and text shot graphs use it, and the clean caches button removes the frames.
- **Another idea**: the Studio has an `idea_seed` setting (0 is the plan there always was) sent to every text model of stage 1, and an « Another idea » button in the art direction panel that prepares a new brief with the next one. Before, the same request always gave the same plan, whatever the job seed.
- **Camera moves**: a `Camera Moves` node gives every shot of the Text and Music workflows a move (twelve in the list), changes the one a shot repeats from the shot before, follows the idea seed and leaves a brief that asks for a fixed camera alone; the art direction camera has four more moves (orbit, push-in, whip pan, crane) and the planner is given the list. A steady camera in the art direction turns the node off.
- **Presets**: eight more presets for Text and Music (night ad with three characters, one place per shot, product reveal, ad with a voice file, slowed dream, monster rap, one subject many places, build and drop).
- **Optional dependencies never block a generation**: the Studio asks ComfyUI which files and nodes it has and cuts out of the prompt the optional branches whose models are missing (the Pika Flex LoRA, the FLUX location images, the pose control of H3, the generated music, which becomes silence with a warning); `Transcribe Voice` now returns empty text whatever goes wrong with Whisper. ComfyUI refused a whole prompt for a file that only a switch could have taken.
- **Best of two takes** (Studio option, off by default, Text and Music): both takes of a shot are generated, with two different seeds (the second take used the seed of the first until now, so a retry repeated it), and the `take_judge` skill makes the local vision model look at six frames of each and answer `BETTER: A` or `BETTER: B`; a take that is black or only noise loses whatever the judge says. The shots stage takes about twice as long.
- **Kinetic lyrics** (Studio option, off by default, Music): `Save Project Lyrics` keeps the transcribed words, with the accents that land on a beat, in the project; the finishing pass adds the `kinetic_lyrics` layer (one word at a time on the seconds it is sung, a bigger colored one on the beats) to the layers of the user, up to the 120 layers a pass takes. The text cards of HyperFrames no longer break a word across two lines.
- **Three treatments** (Studio): `Three treatments` prepares three briefs of the same request in one go, a direct one, one with a twist and one led by the image, and the user keeps one; text only, nothing is generated.
- **Pika H3 Flex** (Studio option, off by default): the shot graphs of Text and Music can generate with the Pika H3 Flex Ref2VA LoRA in six steps (lcm sampler, the six sigmas of the official ComfyUI template) instead of the 8-step turbo LoRA; the two are never stacked. Needs `pika_h3_flex_ref2va_v1_bf16.safetensors` in the loras folder.
- **Ad with a voice** (Text mode): with the voice option and no typed dialogue, the voice file is read with Whisper, its lines go to the story and the planners, and each shot gets the lines that start inside it as spoken words (`Apply Casting` `spoken`, `Transcribe Voice` `spoken` and `enabled`, audio now optional). Typed dialogue still wins.
- **Preserved dialogue no longer fails the export**: with `preserve_dialogue`, each shot now keeps the part of its take that its shot uses, instead of the whole take; a take longer than its shot (H3 makes at least 124 frames) used to push the dialogue past the end of the video and stop the assembly. In the Studio, a voice longer than the edit only adds a warning to the job.
- **Text mode**: the Studio text workflow now writes the story of the edit before planning the shots, and, with the casting option (now offered in Text too), casts the shots it planned. The visual memory then keeps each character's face from shot to shot, as in Music.
- **Casting by shot id**: when the shot plan is given, the casting planner also writes `shots` (shot id to character id) and `Apply Casting` follows it before the seconds, so a shot shows the character the planner made it for even when the casting seconds disagree.
- **Story of the edit**: a `story_planner` skill and a step in the Studio music workflow write, from the brief, the lyrics and the sections of the music (new `sections_text` output of Music Words), a short story with a part for every section; the shot planner and the casting both read it, so the shots and the cast follow one thread.
- **Audio anchored under each shot**: with music sync on (the default for new jobs), H3 gets the part of the music of each shot anchored at the start of the take, through Add Guide, instead of a loose reference; AI Edit candidates skip it.
- **Lyrics in each shot**: `Apply Casting` takes `words_json`; each shot gets the words that start inside it at the end of its prompt, and the H3 shot prompt skill keeps them word for word.
- **Phrase cuts from words**: `Create Timeline` takes `words_json` (from Music Words); in the phrases mode the cuts fall in the pauses between the phrases of the words, else in the pauses of the detected voice.
- **Character references**: `Apply Casting` takes `references_json` ({character: pictures}), carried in `plan.cast.references` of every shot of that character, and outputs `character_sheets_json`, a prompt per character to make its reference picture once.
- **Creative Director** (`core/creative_director.py`): `"shot_sizes": "auto"` in a casting chooses each size from the duration, the energy (`shot_energy_json`) and the place of the shot; the same size never comes three times in a row.
