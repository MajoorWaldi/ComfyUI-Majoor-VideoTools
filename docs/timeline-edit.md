# Timeline Edit

Connect a shot list to **Timeline Edit**, then its output to **Shot Assemble**. Optional music passes through the editor. For post-generation work, load a retained shot list instead of rerunning the generation graph.

The shared frame-based editor supports trim/slip, cutting, reorder, duplicate/delete, occurrence-local take selection, undo/redo, waveform, seek and frame steps. It edits retained raw takes. Save and export explicitly; the source takes are preserved.

HyperKut Studio uses the same editor through its Manual montage adapter. Preview can pause at source switches. Experimental AI extensions and retiming of music/overlays require separate review; they are not implied by ordinary trimming.
